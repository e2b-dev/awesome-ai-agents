## [GolemCore Bot](https://github.com/alexk-dev/golemcore-bot)
AI agent framework for Java ? skill-based architecture with MCP support, tool calling, RAG, and Telegram integration.

<details>

### Category
General purpose, Build your own, Framework

### Description
- **Intelligent Processing**: Hybrid Skill Routing (semantic search + LLM classifier) and dynamic model tier selection.
- **MCP Support**: Integration with Model Context Protocol for external tool servers.
- **Sandboxed Execution**: Isolated workspace with path traversal protection and user approval workflow for destructive operations.
- **Multi-channel**: Native Telegram integration with voice, file uploads, and long-polling support.
- **Advanced RAG**: Knowledge graph-based long-term memory via LightRAG.
- **Built on Java**: Developed using Spring Boot and LangChain4j for enterprise-grade stability.
